# Sanskriti — Romantic Experience ♡

A cinematic, frontend-first romantic birthday website using **Node.js + Express**.

No database. No `.env`. No backend data storage.

## Folder structure

```text
sanskriti_romantic_experience/
├── package.json
├── server.js
├── README.md
└── public/
    ├── index.html
    ├── styles.css
    ├── script.js
    └── assets/
        └── song.mp3   <-- put your downloaded MP3 here
```

## Run locally

1. Install Node.js.
2. Put your downloaded MP3 at:

```text
public/assets/song.mp3
```

3. In this folder:

```bash
npm install
npm start
```

4. Open:

```text
http://localhost:3000
```

For development with Node's watch mode:

```bash
npm run dev
```
